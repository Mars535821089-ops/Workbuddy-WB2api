## 未直接采用的建议

- 不把默认全局并发从 3 调高为 8，避免无测量依据地增加账号负载。
- 不使用同步 `time.sleep` 增加选号等待；沿用现有异步等待，并修正为账号级上限。
- `0` 不限仍检查维护锁；PR 中无上限直接放行的分支会绕过维护互斥。
- 不默认阻断非本机管理访问，也不阻断公开加入页和静态文件。Docker、反向代理和远程管理依赖这些路径；管理操作已有令牌校验。监听地址继续由对应部署入口配置，不展示“保存即生效”的错误承诺。
- 不采用全系统搜索 `main.py`、`uvicorn` 或 `daemon.ps1` 后结束进程的逻辑，避免误伤其他项目；也不采用 Windows BAT 的 `/dev/null` 重定向。
- 不添加“所有 slash 命令都必须调用工具”的通用指令，不声称网关未实现的 Responses 内置工具已经由 harness 提供。
- 保留本地凭据、排障脚本和历史测试的忽略规则，只加入本次可独立运行且使用临时数据库的维护回归脚本。

## 数据与部署边界

奖励日志来自实际领奖结果，不以余额增加推断来源。一个巡检内的奖励按分项记录，不再重复记录汇总；补偿使用活动标识去重，并与已领取状态一并保存。刷新到的余额只表示本次观察值，不假定是每个分项发放瞬间的精确余额。没有记录的余额显示“未记录”。初次导入/同步只建立余额基线。

SQLite 备份使用在线备份 API，覆盖 WAL 中已提交的数据，并执行完整性校验。下载需要管理员令牌，响应禁止缓存，完成后清理临时文件。MySQL 不会伪装成已备份成功。

#27 实现 issue 明确接受的第一阶段；不提供从 Web 服务执行任意主机命令、自动重建容器或自动重启。升级前由管理员下载备份，使用页面命令或 NAS 容器管理器执行更新。

本次处理提交源码与关闭条目，不包含线上部署、版本号变更或安装包/Release 发布。
